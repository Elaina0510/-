# 概率论与数理统计：参数估计知识点汇总

---

## 一、 点估计（Point Estimation）

点估计是通过构造样本的函数（估计量）来直接给出未知参数的某个具体数值。

### 1. 矩估计法（Method of Moments）

* **核心思想**：用样本的各阶原点矩（如样本均值）作为总体各阶原点矩（如总体期望）的估计量。依大数定律，当样本量足够大时，样本矩依概率收敛于总体矩。

* **计算步骤**：
  1. 计算总体的理论期望（一阶原点矩）或高阶矩：$A_k = E(X^k) = g_k(\theta_1, \theta_2, \cdots, \theta_m)$。
  2. 计算对应的样本矩：$B_k = \frac{1}{n}\sum_{i=1}^n X_i^k$（一阶时即为样本均值 $\bar{X}$）。
  3. 建立方程组并求解：令 $A_k = B_k$，从中反解出未知参数 $\hat{\theta}_i$。

* **延伸拓展**：矩估计的优点是不需要知道总体的具体分布形式（只需知道前几阶矩的结构即可），但其估计精度通常不如最大似然估计，且有时解出的估计值可能超出参数的实际取值范围。

### 2. 最大似然估计法（Maximum Likelihood Estimation, MLE）

* **核心思想**：在已知的试验结果下，寻找能使该组样本观测值出现概率（似然度）达到最大的参数值作为估计值。

* **似然函数（Likelihood Function）的构造**：
  * **离散型总体**：$L(\theta) = \prod_{i=1}^n P(X = x_i; \theta)$（所有观测值对应概率的乘积）。
  * **连续型总体**：$L(\theta) = \prod_{i=1}^n f(x_i; \theta)$（所有观测值对应概率密度的乘积）。

* **求解分类（⚠️大题必考点）**：
  * **正规情况（可导型）**：似然函数连续可导。通过取对数将乘积化为求和，即对数似然函数 $\ln L(\theta)$。通过求导并令其为 $0$（解似然方程 $\frac{d\ln L(\theta)}{d\theta} = 0$）来寻找驻点。
  * **非正规情况（边界/非可导型）**：总体的取值范围（支撑集）依赖于未知参数（例如均匀分布 $U(0,\theta)$ 或双参数指数分布 $t \ge c$）。似然函数随参数呈单调递增或递减，**无法通过求导解决**。此时必须结合边界条件，利用**顺序统计量**（如最小样本值 $X_{(1)}$ 或最大样本值 $X_{(n)}$）来确定使似然函数最大的边界点。

## 二、 估计量的评选标准（Criteria for Estimators）

同一个参数可以有多种不同的估计量，需要一套标准来衡量"谁的估计效果更好"。

### 1. 无偏性（Unbiasedness）

* **定义**：若估计量 $\hat{\theta}$ 的数学期望等于被估计参数的真实值，即 **$E(\hat{\theta}) = \theta$**，则称 $\hat{\theta}$ 是 $\theta$ 的无偏估计量。

* **核心性质与计算技巧**：
  * 利用数学期望的线性性质：$E(aX + bY) = aE(X) + bE(Y)$。
  * **非线性非无偏性（重要定理）**：若 $\hat{\theta}$ 是 $\theta$ 的无偏估计，且方差 $D(\hat{\theta}) > 0$，则其非线性映射（如平方 $\hat{\theta}^2$）往往不再是对应映射（$\theta^2$）的无偏估计。由于 $E(\hat{\theta}^2) = D(\hat{\theta}) + [E(\hat{\theta})]^2 = D(\hat{\theta}) + \theta^2 > \theta^2$，因此平方估计通常存在**正偏（高估）**。

### 2. 有效性（Efficiency）

* **定义**：在所有**无偏估计量**中，方差最小的那个估计量被认为是最有效的。若 $E(\hat{\theta}_1) = E(\hat{\theta}_2) = \theta$，且 **$D(\hat{\theta}_1) < D(\hat{\theta}_2)$**，则称 $\hat{\theta}_1$ 比 $\hat{\theta}_2$ 更有效。

* **计算技巧**：利用独立随机变量的方差性质：$D(\sum a_i X_i) = \sum a_i^2 D(X_i)$（要求 $X_i$ 相互独立）。通过权重的平方和大小来判断哪一个估计量的波动更小。

* **延伸拓展（一致最小方差无偏估计 - UMVUE）**：如果在某个参数的所有无偏估计中，能找到一个估计量在参数的一切可能取值下方差都达到最小，它就是UMVUE。样本均值 $\bar{X}$ 在许多常见分布（如正态分布、指数分布）中都是UMVUE。

### 3. 一致性/相合性（Consistency）

* **定义**：当样本量 $n \to \infty$ 时，估计量 $\hat{\theta}_n$ 依概率收敛于未知参数 $\theta$，即对任意 $\epsilon > 0$，$\lim_{n \to \infty} P(|\hat{\theta}_n - \theta| < \epsilon) = 1$。这是大样本理论下的基本要求。

## 三、 区间估计（Interval Estimation）

区间估计旨在给出一个随机区间，并指出该区间包含未知参数真实值的概率（置信水平）。

### 1. 核心概念

* **置信水平（Confidence Level）**：$1 - \alpha$。表示该区间方法在重复抽样中包含真实参数的概率，常见取值为 $0.95$ 或 $0.99$。$\alpha$ 称为显著性水平。

* **枢轴量（Pivotal Quantity）**：构造区间的核心工具。它必须满足两个条件：
  1. 包含待估参数，且是样本的函数。
  2. 其**分布形式必须完全已知**，不依赖于任何未知参数。

### 2. 单个正态总体均值 $\mu$ 的区间估计

根据总体方差 $\sigma^2$ 是否已知，选择不同的枢轴量：

| 场景条件 | 选用枢轴量及分布 | 置信区间公式（双侧） |
| --- | --- | --- |
| **方差 $\sigma^2$ 已知** | $Z = \frac{\bar{X} - \mu}{\sigma / \sqrt{n}} \sim N(0, 1)$ | $\left[ \bar{x} - z_{\alpha/2} \frac{\sigma}{\sqrt{n}}, \ \bar{x} + z_{\alpha/2} \frac{\sigma}{\sqrt{n}} \right]$ |
| **方差 $\sigma^2$ 未知** | $t = \frac{\bar{X} - \mu}{S / \sqrt{n}} \sim t(n-1)$ | $\left[ \bar{x} - t_{\alpha/2}(n-1) \frac{s}{\sqrt{n}}, \ \bar{x} + t_{\alpha/2}(n-1) \frac{s}{\sqrt{n}} \right]$ |

*注：其中 $S = \sqrt{\frac{1}{n-1}\sum(X_i - \bar{X})^2}$ 为样本标准差。*

### 3. 两个独立正态总体均值差 $\mu_1 - \mu_2$ 的区间估计

当两个总体的方差 $\sigma_1^2 = \sigma_2^2 = \sigma^2$ **未知但相等**时：

* **联合样本方差（Pooled Variance）**：

$$S_w^2 = \frac{(n_1 - 1)S_1^2 + (n_2 - 1)S_2^2}{n_1 + n_2 - 2}$$

* **选用枢轴量**：

$$t = \frac{(\bar{X}_1 - \bar{X}_2) - (\mu_1 - \mu_2)}{S_w \sqrt{\frac{1}{n_1} + \frac{1}{n_2}}} \sim t(n_1 + n_2 - 2)$$

* **置信区间公式**：

$$\left[ (\bar{x}_1 - \bar{x}_2) \pm t_{\alpha/2}(n_1+n_2-2) \cdot s_w \sqrt{\frac{1}{n_1} + \frac{1}{n_2}} \right]$$

### 4. 单侧置信限（One-sided Confidence Bounds）

当实际应用中只关心参数的单侧界限（如"寿命的下限"或"杂质含量的上限"）时，使用单侧置信区间。它将不确定性风险 $\alpha$ 全部凝聚在某一侧，而非像双侧区间那样两边平分 $\alpha/2$。

* **单侧置信上限 $\mu_U$**：形式为 $(-\infty, \ \mu_U]$。
  * 已知方差场景：$\mu_U = \bar{x} + z_{\alpha} \frac{\sigma}{\sqrt{n}}$

* **单侧置信下限 $\mu_L$**：形式为 $[\mu_L, \ +\infty)$。
  * 未知相等方差（双总体）场景：$\mu_L = (\bar{x}_1 - \bar{x}_2) - t_{\alpha}(n_1+n_2-2) \cdot s_w \sqrt{\frac{1}{n_1} + \frac{1}{n_2}}$

## 四、 本章高频核心公式（考前必备）

1. **样本方差计算（除以 $n-1$）**：

$$S^2 = \frac{1}{n-1} \left( \sum_{i=1}^n X_i^2 - n\bar{X}^2 \right)$$

2. **指数分布的记忆性质**：

若 $X \sim \mathrm{Exp}(\lambda)$，则 $E(X) = \frac{1}{\lambda}$， $D(X) = \frac{1}{\lambda^2}$。对于双参数指数分布 $f(t) = \frac{1}{\theta}e^{-(t-c)/\theta}$，其 $E(X) = c + \theta$， $D(X) = \theta^2$。

3. **分位数查找关系**：
   * 标准正态分布：$z_{1-\alpha} = -z_{\alpha}$
   * $t$ 分布：具有对称性， $t_{1-\alpha}(df) = -t_{\alpha}(df)$
