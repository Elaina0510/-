# 概率论与数理统计：中心极限定理及相关知识点汇总

---

## 一、 核心基础：常见分布的数字特征

在应用中心极限定理之前，必须先准确提取单个随机变量的**数学期望（均值） $E(X)$** 和 **方差 $D(X)$**。

### 1. 指数分布（Exponential Distribution）

若 $X \sim \mathrm{Exp}(\lambda)$：
* 数学期望：$E(X) = \frac{1}{\lambda}$
* 方差：$D(X) = \frac{1}{\lambda^2}$

**核心性质：** **指数分布的方差等于数学期望的平方**，即 $D(X) = [E(X)]^2$（或等价地，标准差等于期望：$\sqrt{D(X)} = E(X)$）。

### 2. 均匀分布（Uniform Distribution）

若 $X \sim U(a, b)$：
* 数学期望：$E(X) = \frac{a+b}{2}$
* 方差：$D(X) = \frac{(b-a)^2}{12}$

### 3. 离散型分布与其它连续分布

* **离散型分布：** 给出分布律表格，需通过定义法求解：
  * $E(X) = \sum x_i p_i$
  * $D(X) = E(X^2) - [E(X)]^2$

* **韦布尔分布（Weibull Distribution）等复杂连续分布：** 考试通常不会让你直接积分求期望方差，题目会直接给出已知数据，直接提取 $\mu$ 和 $\sigma^2$ 即可。

## 二、 关键工具：随机变量序列的数字特征线性性质

中心极限定理处理的是"多个随机变量的组合"，因此必须掌握期望与方差的合成规则：

### 1. 期望的线性性质（对任意变量均成立）

$$E(X_1 + X_2 + \dots + X_n) = E(X_1) + E(X_2) + \dots + E(X_n)$$

$$E(X - Y) = E(X) - E(Y)$$

### 2. 方差的线性性质（⚠️ 仅在变量间**相互独立**时成立）

$$D(X_1 + X_2 + \dots + X_n) = D(X_1) + D(X_2) + \dots + D(X_n)$$

$$D(X - Y) = D(X) + D(Y) \quad (\mathrm{注意：独立变量相减，方差依然相加})$$

## 三、 灵魂定理：中心极限定理（CLT）的应用模型

### 模型 1：独立同分布的"总和"模型（林德伯格-列维定理）

* **适用场景：** 求解形如"$n$ 个元件的寿命**总和**"、"$n$ 笔理赔的**总金额**"、"$n$ 个误差的**总和**"大于或小于某个特定值的概率。

* **定理内容：** 设 $X_1, X_2, \dots, X_n$ 独立同分布，且 $E(X_i) = \mu$，$D(X_i) = \sigma^2$。当 $n$ 较大时，总和 $S_n = \sum_{i=1}^n X_i$ 近似服从正态分布：

$$S_n \sim N(n\mu, \, n\sigma^2)$$

* **标准化大招公式：**

$$P\left\{a < \sum_{i=1}^{n}X_i < b\right\} \approx \Phi\left(\frac{b - n\mu}{\sqrt{n}\sigma}\right) - \Phi\left(\frac{a - n\mu}{\sqrt{n}\sigma}\right)$$

### 模型 2：独立同分布的"算术平均值"模型

* **适用场景：** 求解形如"一年 52 周事故发生数的**算术平均值 $\bar{X}$**"在某个区间内的概率。

* **定理内容：** 设 $X_1, X_2, \dots, X_n$ 独立同分布，且 $E(X_i) = \mu$，$D(X_i) = \sigma^2$。当 $n$ 较大时，算术平均值 $\bar{X} = \frac{1}{n}S_n$ 近似服从正态分布：

$$\bar{X} \sim N\left(\mu, \, \frac{\sigma^2}{n}\right)$$

* **标准化公式：**

$$Z = \frac{\bar{X} - \mu}{\frac{\sigma}{\sqrt{n}}}$$

### 模型 3：双样本"算术平均值之差"模型

* **适用场景：** 求解形如"两组独立测量的算术平均值之差 $\bar{X} - \bar{Y}$"的概率。

* **定理内容：** 若 $\bar{X} \sim N\left(\mu_x, \frac{\sigma_x^2}{n_x}\right)$ 且 $\bar{Y} \sim N\left(\mu_y, \frac{\sigma_y^2}{n_y}\right)$，由于正态分布的再生性，两独立正态变量之差仍为正态分布：

$$(\bar{X} - \bar{Y}) \sim N\left(\mu_x - \mu_y, \,\, \frac{\sigma_x^2}{n_x} + \frac{\sigma_y^2}{n_y}\right)$$

### 模型 4：二项分布的正态近似（棣莫弗-拉普拉斯定理）

* **适用场景：** 当 $X \sim B(n, p)$ 且 $n$ 很大时，可看作 $n$ 个独立的 0-1 分布之和，此时 $X$ 近似服从正态分布：

$$X \sim N(np, \, np(1-p))$$

## 四、 落地执行：标准正态分布的计算与查表技巧

无论前面的模型多么复杂，最终一步都是将结果化为标准正态分布变量 $Z \sim N(0, 1)$ 进行查表。需熟练掌握以下性质：

1. **分布函数性质：** $P(Z \le x) = \Phi(x)$。
2. **区间概率转换：** $P(c < Z < d) = \Phi(d) - \Phi(c)$。
3. **对称性公式（处理负数）：** $\Phi(-x) = 1 - \Phi(x)$。
4. **对称区间公式：** $P(-x < Z < x) = 2\Phi(x) - 1$。

## 五、 逆向思维：反求样本量 $n$ 或临界值 $L$

除了正面求解概率，考试也非常喜欢考察逆向推导，通常有以下两类：

1. **已知概率上限/下限，反求最多/最少样本量 $n$：** 需要根据给定的概率（如 $\ge 0.90$）反查标准正态分布表找到分位数（如 $\Phi(1.645) = 0.95$），列出关于 $n$ 的不等式进行求解。

2. **已知概率，反求边界临界值 $L$：** 给定 $P(\bar{X} > L) \le 0.01$，需转化为标准正态分布后，通过已知概率查出分位数，反推出 $L$ 的值。
