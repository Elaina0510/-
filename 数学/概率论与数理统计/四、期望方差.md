# 概率论与数理统计：数学期望与方差知识点汇总

---

## 一、 数学期望与方差的定义与核心公式

### 1. 数学期望 (Mathematical Expectation)

期望本质上是随机变量取值的**加权平均数**。

* **离散型随机变量：** 若 $X$ 的分布律为 $P\{X = x_i\} = p_i$，则：

$$EX = \sum_{i} x_i p_i$$

* **连续型随机变量：** 若 $X$ 的概率密度函数为 $f(x)$，则：

$$EX = \int_{-\infty}^{+\infty} x f(x) \, dx$$

### 2. 随机变量函数的期望 (定理)

求 $Y = g(X)$ 或 $Z = g(X, Y)$ 的期望时，**不需要**先求出新变量 $Y$ 或 $Z$ 的分布，可直接利用原分布计算：

* **一维连续型：** $E[g(X)] = \int_{-\infty}^{+\infty} g(x) f(x) \, dx$

* **二维连续型：** $E[g(X, Y)] = \int_{-\infty}^{+\infty} \int_{-\infty}^{+\infty} g(x, y) f(x, y) \, dx dy$

### 3. 方差 (Variance)

方差度量的是随机变量与其均值的**偏离程度（波动大小）**。

* **定义式：** $DX = E\{[X - E(X)]^2\}$

* **最常用计算变形公式（核心必背）：**

$$DX = EX^2 - (EX)^2$$

* **性质判定：** 因为是平方的均值，所以任何随机变量的方差均满足：

$$DX \ge 0 \Rightarrow (EX)^2 \le EX^2$$

*(只有当 $X$ 为常数时，等号成立。)*

### 4. 标准差（Standard Deviation）

* **定义**：方差的算术平方根，记为 $\sigma(X) = \sqrt{D(X)}$。

* **引入原因**：方差的单位是原变量单位的平方（如 $\mathrm{h}^2$），为了使波动指标与原随机变量具有相同的量纲（单位），故对其开方。

## 二、 期望与方差的核心线性性质

这些性质是简化计算、拆分复杂公式的绝对王牌。

### 1. 数学期望的性质（完全线性）

1. **常数的期望：** $E(C) = C$
2. **线性组合：** $E(aX + b) = aEX + b$
3. **和的期望：** $E(X \pm Y) = EX \pm EY$ （**注意：无论 $X$ 与 $Y$ 是否独立，此式恒成立**）。
4. **独立乘积：** 若 $X$ 与 $Y$ **相互独立**，则 $E(XY) = EX \cdot EY$。

### 2. 方差的性质

1. **常数的方差：** $D(C) = 0$
2. **线性组合：** $D(aX + b) = a^2 DX$ （**常数 $b$ 对方差无影响，系数 $a$ 提取出来必须平方**）。
3. **和差的方差：**
   * 若 $X$ 与 $Y$ **相互独立**，则 $D(X + Y) = D(X - Y) = DX + DY$ （**注意：不管是加还是减，方差一律相加**）。
   * 若不独立：
     - $D(X + Y) = DX + DY + 2\mathrm{Cov}(X,Y)$
     - $D(X - Y) = DX + DY - 2\mathrm{Cov}(X,Y)$

## 三、 经典一维概率分布的期望与方差

| 分布名称 | 符号 | 期望 $EX$ | 方差 $DX$ | 备注/巧记 |
| --- | --- | --- | --- | --- |
| **0-1 分布** | $B(1, p)$ | $p$ | $p(1-p)$ | 基础单元，记作 $pq$ （$q=1-p$） |
| **二项分布** | $B(n, p)$ | $np$ | $np(1-p)$ | 0-1 分布的 $n$ 倍叠加 |
| **泊松分布** | $P(\lambda)$ | $\lambda$ | $\lambda$ | **期望 = 方差** |
| **几何分布** | $G(p)$ | $\frac{1}{p}$ | $\frac{1-p}{p^2}$ | 第一次成功所需的平均次数 |
| **均匀分布** | $U(a, b)$ | $\frac{a+b}{2}$ | $\frac{(b-a)^2}{12}$ | 期望在正中间，方差分母为 12 |
| **指数分布** | $\mathrm{Exp}(\lambda)$ | $\frac{1}{\lambda}$ | $\frac{1}{\lambda^2}$ | **方差 = 期望的平方** |
| **正态分布** | $N(\mu, \sigma^2)$ | $\mu$ | $\sigma^2$ | 参数即答案（注意防范题目给标准差 $\sigma$） |

### 速记要点

1. **二项分布**：$n$ 个独立的 0-1 分布之和，期望和方差直接在 0-1 分布的基础上乘以 $n$。

2. **泊松分布**：**"期望等于方差"**。

3. **几何分布**：独立重复试验中，直到**第一次成功**时所需要的试验次数。

4. **均匀分布**：期望就是区间的**中点**；方差分母固定是 **12**，分子是区间长度的平方。

5. **指数分布**：方差是期望的平方。注意题目给出的密度函数形式：
   * 若 $f(x)=\lambda e^{-\lambda x}$，则参数是 $\lambda$，期望是 $1/\lambda$，方差是 $1/\lambda^2$。
   * 若 $f(x)=\frac{1}{\theta} e^{-\frac{x}{\theta}}$，那么期望就是 $\theta$，方差就是 $\theta^2$。

6. **正态分布**：无需计算，符号里的两个参数本身就是期望和方差。标准正态分布 $N(0, 1)$ 的 $EX=0, DX=1$。

## 四、 二维随机变量的数字特征

当引入二维随机变量 $(X, Y)$ 时，考查重点转向空间积分与变量间的几何对称性。

### 1. 边缘期望的直接计算

* 虽可通过先求边缘密度再求期望，但更推荐**直接利用联合密度进行二重积分**：
  * $E(X) = \int_{-\infty}^{+\infty} \int_{-\infty}^{+\infty} x \cdot f(x, y) \, dx dy$
  * $E(Y) = \int_{-\infty}^{+\infty} \int_{-\infty}^{+\infty} y \cdot f(x, y) \, dx dy$

### 2. 积分与区域的对称性原理（高级秒杀技巧）

若二维联合密度函数 $f(x, y)$ 在其非零定义域区域 $D$ 上具有关于直线 $y = x$ 的对称性：

1. **区域对称：** 区域 $D$ 关于 $y = x$ 轴对称。
2. **函数对称：** 满足 $f(x, y) = f(y, x)$。

则 $X$ 与 $Y$ 具有完全相同的边缘分布，可直接断定：

$$E(X) = E(Y)$$

$$EX^2 = EY^2$$

### 3. 协方差（Covariance）

协方差用以衡量两个随机变量的总体线性相关趋势。

* **计算公式**：$\mathrm{Cov}(X,Y) = E[(X-E[X])(Y-E[Y])] = E[XY] - E[X]E[Y]$

### 4. 相关系数（Correlation Coefficient）

消除量纲影响后的标准化协方差，用以衡量线性相关程度。

* **计算公式**：$\rho_{xy} = \frac{\mathrm{Cov}(X,Y)}{\sqrt{D(X)}\sqrt{D(Y)}}$

## 五、 独立性 vs 不相关性（核心高频考点）

| 概念 | 定义方法 | 数学判别式 | 物理意义 |
| --- | --- | --- | --- |
| **相互独立** | 联合分布等于边缘分布的乘积 | $f(x,y) = f_X(x)f_Y(y)$ | 一个变量的取值**完全不影响**另一个变量的概率分布。 |
| **不相关** | 协方差或相关系数为零 | $\mathrm{Cov}(X,Y) = 0$ 或 $E[XY] = E[X]E[Y]$ | 两个变量之间**没有线性关系**（但可能有非线性关系）。 |

### 扩展关系定理

1. **独立 $\Rightarrow$ 不相关**：若 $X$ 和 $Y$ 独立，则必然有 $\mathrm{Cov}(X,Y) = 0$。
2. **不相关 $
ot\Rightarrow$ 独立**：反之不成立。协方差可以为0（不相关），但它们在分布上依然互相制约（不独立）。
3. **特例（二维正态分布）**：若 $(X,Y)$ 服从二维正态分布，则"独立"与"不相关"是**等价**的。

## 六、 高频解题工具与数学方法

### 1. 阶梯状分段分布函数的处理（离散型）

若已知分布函数 $F(x)$ 是分段常数，求期望的方法：

* 寻找所有的跳跃间断点 $x_i$，这些点即为离散变量的取值。
* 计算跳跃高度 $p_i = F(x_i) - F(x_i^-)$。
* 列出分布律，代入离散型期望公式 $EX = \sum x_i p_i$。

### 2. 无穷递减等比数列级数求和

在处理如 $\frac{1}{2^k}$ 或 $\frac{2}{3^k}$ 这种离散无穷分布律时，必用公式：

$$S = \frac{a_1}{1 - q} \quad (|q| < 1)$$

*其中 $a_1$ 为级数展开后的第一项，$q$ 为公比。*

### 3. 高斯积分（概率积分常数）

在解决正态分布衍生或含有 $e^{-ax^2}$ 形式的连续型积分时，必备的高数基础：

* 全区高斯积分：
$$\int_{-\infty}^{+\infty} e^{-x^2} \, dx = \sqrt{\pi}$$

* 半区高斯积分：
$$\int_{0}^{+\infty} e^{-x^2} \, dx = \frac{\sqrt{\pi}}{2}$$

### 4. 伽马函数 ($\Gamma$ 函数) —— 进阶扩展

对于形如 $\int_{0}^{+\infty} x^n e^{-ax} \, dx$ 或含有指数平方项的积分，可使用伽马函数速算：

* 定义： $\Gamma(s) = \int_{0}^{+\infty} t^{s-1} e^{-t} \, dt$
* 性质： $\Gamma(s+1) = s\Gamma(s)$
* 常用特值： $\Gamma(\frac{1}{2}) = \sqrt{\pi}$， $\Gamma(1) = 1$， $\Gamma(n) = (n-1)!$（$n$为正整数）。

### 5. 区域对称性与奇偶性定理（简化二重积分神器）

在连续型期望的计算中：

* 若积分区域关于 $y$ 轴对称，且被积函数关于 $x$ 是**奇函数**，则对 $x$ 的积分直接为 0。
* 若积分区域关于 $x$ 轴对称，且被积函数关于 $y$ 是**奇函数**，则对 $y$ 的积分直接为 0。

### 6. 轮换对称性

当积分区域是正方形 $0 \le x \le a, 0 \le y \le a$，且联合密度 $f(x,y)$ 中 $x$ 与 $y$ 的地位完全对等时，直接可得 $E[X] = E[Y]$ 以及 $D(X) = D(Y)$，从而减少一半的运算量。

### 7. 极坐标变换（Polar Coordinates）

当连续型随机变量的积分区域与圆形、圆环相关（如 $x^2+y^2 \le 1$）时，使用极坐标变换 $x = r\cos\theta, y = r\sin\theta, dxdy = r\,drd\theta$ 能将复杂的代数积分转换为简单易积的三角函数积分。

### 8. 切比雪夫不等式

设随机变量 $X$ 的数学期望 $EX = \mu$，方差 $DX = \sigma^2$，则对任意 $\varepsilon > 0$，有：

$$P\{|X - \mu| \ge \varepsilon\} \le \frac{\sigma^2}{\varepsilon^2}$$

或等价形式：

$$P\{|X - \mu| < \varepsilon\} \ge 1 - \frac{\sigma^2}{\varepsilon^2}$$
